## Тематика сайта, название

Веб-сервис для поиска напарников и формирования команд в компьютерных играх (LFG — Looking For Group).

**Название проекта: LFG Hub**

**Суть:** Платформа, где игроки публикуют объявления о поиске тиммейтов для совместной игры. Можно указать конкретную игру, желаемый ранг/уровень, удобное время для игры и способ голосовой связи. Другие пользователи просматривают ленту объявлений, фильтруют по играм и находят подходящих напарников.

## Цель и задачи системы

**Цель:** Разработать удобный веб-сервис, который упрощает поиск напарников в мультиплеерных играх, позволяя игрокам быстро находить команду по интересам, рангу и времени игры.

**Задачи системы:**

1. Реализовать регистрацию и аутентификацию пользователей с хешированием паролей.
2. Обеспечить полный цикл CRUD для объявлений о поиске тиммейтов (создание, просмотр, редактирование, удаление).
3. Реализовать каталог игр с возможностью добавления новых игр администратором.
4. Обеспечить фильтрацию объявлений по игре, рангу и статусу (активно/закрыто).
5. Реализовать систему ролей: обычный пользователь управляет только своими объявлениями, администратор может модерировать все объявления.
6. Предоставить REST API для получения списка объявлений и игр в формате JSON.
7. Обеспечить защиту от несанкционированного доступа к чужим данным (пользователь не может редактировать или удалять чужое объявление).
8. Создать адаптивный интерфейс с использованием Bootstrap, читаемый как на ПК, так и на мобильных устройствах.

## Целевая аудитория

**Основная аудитория — игроки в мультиплеерные компьютерные игры:**

- Игроки в соревновательные шутеры (CS2, Valorant, Overwatch), ищущие напарников своего ранга для рейтинговых матчей.
- Игроки в MOBA (Dota 2, League of Legends), формирующие пати для совместной игры и поднятия рейтинга.
- Игроки в кооперативные игры (Phasmophobia, Lethal Company, Dead by Daylight), ищущие компанию для вечерних каток.
- Игроки в MMORPG (World of Warcraft, FFXIV), собирающие группу для рейдов и данжей.

**Отличие от обобщённого пользователя Интернета:** аудитория точно знает игровую терминологию (ранги, роли, рейтинг ELO, Discord), ожидает минималистичный и быстрый интерфейс без лишней информации. В дизайне это учтено: тёмная тема (привычная для геймеров), акцент на фильтрах по играм и рангам, отображение Discord-тега — основного способа связи у геймеров.

## Содержание сайта

1. **Главная страница (лента объявлений)** — список всех активных объявлений с фильтрами по игре, рангу и статусу. Каждое объявление отображается в виде карточки: игра, ник автора, ранг, время игры, голосовой чат.
2. **Страница деталей объявления** — полная информация: описание, контакты автора (Discord/Steam), дата публикации, статус.
3. **Страница создания/редактирования объявления** — форма с выбором игры (выпадающий список), ранга (select), времени для игры (утро/день/вечер/ночь), типа голосовой связи, текстовым полем для описания.
4. **Страница «Мои объявления»** — список объявлений текущего пользователя с возможностью редактирования, закрытия (скрытия из общей ленты) и удаления.
5. **Профиль пользователя** — публичная страница с информацией о пользователе: ник, Discord-тег, описание, список активных объявлений.
6. **Страница входа** — форма авторизации (email + пароль).
7. **Страница регистрации** — форма с полями: имя пользователя, email, пароль, подтверждение пароля, Discord-тег.
8. **Страницы ошибок** — кастомные страницы 404 (не найдено) и 403 (доступ запрещён).

## Функциональные возможности

- **Аутентификация и авторизация:**
  - Регистрация нового пользователя с хешированием пароля (Werkzeug `generate_password_hash`).
  - Вход в систему (Flask-Login) с запоминанием сессии.
  - Выход из системы (logout).
  - Защита маршрутов декоратором `@login_required`.
  - Система ролей: поле `is_admin` в модели User. Администратор может удалять любые объявления и редактировать каталог игр.

- **Управление объявлениями (CRUD):**
  - Создание объявления: выбор игры, ранга, времени, голосового чата, описание.
  - Просмотр ленты с фильтрацией (по игре, статусу) и поиском.
  - Редактирование своего объявления.
  - Изменение статуса (активно → закрыто). Закрытые объявления скрываются из общей ленты, но видны в «Моих объявлениях».
  - Удаление объявления автором или администратором.

- **Каталог игр:**
  - Предустановленный список игр (CS2, Dota 2, Valorant и др.).
  - Администратор может добавлять новые игры через веб-интерфейс.

- **Фильтрация и поиск:**
  - Фильтр по игре (выпадающий список).
  - Фильтр по статусу (активно / все).
  - Текстовый поиск по описанию объявления и нику автора.

- **REST API:**
  - `GET /api/listings` — список объявлений в JSON с возможностью фильтрации через query-параметры (`?game_id=1&status=active`).
  - `GET /api/listings/<id>` — детали одного объявления в JSON.
  - `POST /api/listings` — создание объявления (требуется авторизация, данные в JSON).
  - `PUT /api/listings/<id>` — обновление статуса/содержимого объявления.
  - `GET /api/games` — список всех игр в JSON.

- **Безопасность и защита данных:**
  - Пароли хранятся в хешированном виде.
  - Проверка прав доступа: пользователь не может редактировать/удалять чужие объявления через прямой URL.
  - CSRF-защита для всех веб-форм (Flask-WTF).
  - Серверная валидация форм (длина текста, обязательные поля, корректность email).

- **Интерфейс и статика:**
  - Адаптивный дизайн на Bootstrap 5 (корректное отображение на мобильных устройствах).
  - Тёмная цветовая схема (кастомный CSS поверх Bootstrap).
  - Flash-сообщения об успешных действиях и ошибках.
  - Кастомные страницы ошибок 404 и 403.
